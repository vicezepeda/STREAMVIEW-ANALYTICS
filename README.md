# STREAMVIEW-ANALYTICS
StreamView Analytics dispone de un catálogo de 16.000 películas y 16.000 series. El desafío identificado no es la falta de información, sino la dificultad de convertir un catálogo amplio en evidencia comparable para decisiones de inversión y optimización del portafolio.

# StreamView Analytics

## Descripción

Proyecto de análisis y visualización de datos de películas y series
para apoyar la toma de decisiones sobre contenido en StreamView.

## Objetivo

Analizar el catálogo de películas y series para identificar patrones
en géneros, idiomas, evolución temporal, valoración, interacción
observable y desempeño financiero.

## Datos

Se analizaron:

- 16.000 películas
- 16.000 series
- Período: 2010-2025

## Principales hallazgos

- Drama concentra una proporción importante del catálogo.
- El catálogo acelera su crecimiento después de 2019.
- Las películas presentan mayor cantidad promedio de votaciones
  que las series.
- La información financiera está disponible solo para una parte
  de las películas.
